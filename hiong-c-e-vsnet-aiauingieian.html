      • event 是一个关键字，用于限制 delegate 的功能。EventHandler： delegate 对象的功能比 event 对象更丰富。

    delegate EventHandler 表示一种方法模板：

    • 其第一个参数为 Object 类型
    • 第二个参数类型为 EventArgs
    • 不返回任何结果

    由 Visual Studio 生成的 buttonAfficher 按钮点击处理方法即属于此类：

    
        private void buttonAfficher_Click(object sender, EventArgs e);

    因此，方法 buttonAfficher_Click 对应于由类型 EventHandler 定义的原型。要创建类型为 EventHandler 的对象，请按以下步骤操作：

    EventHandler evtHandler=new EventHandler(méthode correspondant au prototype  défini par le type EventHandler);

    由于方法 buttonAfficher_Click 对应于类型 EventHandler 定义的原型，因此可以写为：

    EventHandler evtHandler=new EventHandler(buttonAfficher_Click);

    类型为 delegate 的变量实际上是 delegate 类型方法的引用列表。 若要向上述变量 evtHandler 添加新方法 M，应使用以下语法：

    evtHandler+=new EvtHandler(M);

    即使 evtHandler 是一个空列表，也可以使用 += 语法。

    让我们回到 [InitializeComponent] 这一行，它向 buttonAfficher 对象的 Click 事件添加了一个事件处理程序：

    
            this.buttonAfficher.Click += new System.EventHandler(this.buttonAfficher_Click);

        // 转移
        private void transfert(ListBox l1, Button button1vers2, Button buttonEffacer1, ListBox l2, Button button2vers1, Button buttonEffacer2) {
            // 将列表 l1 中选中的项目转移到列表 l2
            for (int i = l1.SelectedIndices.Count - 1; i >= 0; i--) {
                // 所选元素的索引
                int index = l1.SelectedIndices[i];
                // 添加到 l2
                l2.Items.Add(l1.Items[index]);
                // 从 l1 中删除
                l1.Items.RemoveAt(index);
            }
            // “清除”按钮
            buttonEffacer2.Enabled = l2.Items.Count != 0;
            buttonEffacer1.Enabled = l1.Items.Count != 0;
            // 转移按钮
            button1vers2.Enabled = false;
}

    • f 行：列表 l1 中所选元素的索引
    • 第 h 行：该元素被添加到列表 l2 中

    • 如果第(d)行的循环是递减的，且刚处理完编号为 n 的元素，接下来它将处理编号为 n-1 的元素。在删除编号为 n 的元素后，编号为 n-1 的元素编号不会改变。因此，它将在下一个循环迭代中被处理。
