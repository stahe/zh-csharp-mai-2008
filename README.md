## 语言与 .NET 平台概述

C# 是一种于 2002 年 2 月正式发布的语言，与微软的 .NET 1.0 平台一同发布，并与该平台有着内在的联系。C# 需要此运行时环境才能运行，该环境提供了一套非常广泛的类。

乍一看，.NET 平台是一个类似于 Java 虚拟机的运行时环境，但存在一些值得注意的差异：

**跨平台**：虽然 Java 从诞生之初就在各种操作系统上运行，但 .NET 最初仅限于 Windows 系统。不过，如今通过 **[Mono](http://www.mono-project.com)** 项目，已可在 Unix 和 Linux 等系统上使用 .NET。


**多语言**：.NET 平台允许运行用不同语言编写的程序，前提是其编译器能生成 IL（中间语言）代码。所有 .NET 类对这些语言均可用，这往往模糊了它们之间的差异；因此，选择哪种 .NET 语言更多是出于个人偏好，而非性能考量。





## 语言演变

2002年（C# 1.0）时，该语言与Java非常相似，这使得在两种环境之间切换变得更加容易。此后，两种语言的特定特征变得更加鲜明。

随着 C# 3.0 和 .NET 3.5 框架的推出，出现了许多新功能，其中最显著的可能是 **LINQ**（语言集成查询）。LINQ 允许以统一的方式（类似于 SQL）查询数组、列表、数据库或 XML 文件。

> 
> **注**：本文并非完整的课程，也不涉及 LINQ。它面向那些已有一定编程经验并希望学习 C# 基础知识的人士。本文是对 2002 年发布的原始文档的修订版。
